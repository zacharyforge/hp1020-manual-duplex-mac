# HP1020 macOS 手动双面打印

[English](README.md)

这是一个用于 HP LaserJet 1020 / 1020 Plus 的原生 macOS 手动双面打印辅助程序。它不会安装或分发惠普打印机驱动，而是负责拆分 PDF 的奇数页和偶数页、打印第一面、等待用户确认重新放纸，然后再打印第二面。

## 功能

- 中文、英文界面，双语“语言 / Language”选项固定在窗口右上角。
- 新增由两张重叠纸张组成的简洁原生 App 图标。
- 长边装订：像书一样左右翻页。
- 短边装订：像台历一样上下翻页。
- 支持“全部页”或连续页码范围打印；即使所选范围从原文档偶数页开始，也会按所选范围正确配对正反面。
- 选择或打开 PDF 只会选中文件；必须另外点击“开始打印”才会提交打印任务。
- 单页或双面打印成功后只在状态栏显示完成信息，不再弹出完成窗口；错误提示仍保留。
- 真正的两阶段流程：只有勾选重新放纸确认框后，程序才会创建第二面打印任务。
- 内置带有大号顶边标记的双语两页方向测试。
- 标准队列名不可用时，自动寻找名称中含 `1020` 的打印队列。
- 同时支持 Apple 芯片和 Intel Mac 的通用二进制程序。

## 使用条件

- macOS 13 或更高版本。
- 已经能够正常打印的 HP LaserJet 1020 / 1020 Plus 队列。打印驱动以及可能需要的固件加载程序必须事先安装完成。
- `qpdf`，通常可使用 `brew install qpdf` 安装。
- A4 纸。版本 4 会以 A4 和适合页面选项提交任务。

程序首先尝试 `HP_LaserJet_1020` 队列；如果找不到，就使用第一个名称中含 `1020` 的可用队列。

## 打印驱动准备

本项目是手动双面打印辅助程序，不是打印机驱动。使用本程序之前，HP 1020 必须已经能够在 macOS 中正常打印。

现代 macOS 的精简社区驱动安装方案可参考 [anxkhn/hp1020-driver-mac](https://github.com/anxkhn/hp1020-driver-mac/blob/main/README.md)。该项目说明了如何使用 Apple HP Printer Drivers 5.1.1 软件包中的必要组件，并通过兼容的 LaserJet 1022 PPD 驱动 HP 1020。

本项目不包含、复制或重新分发上述驱动文件。请单独按照引用项目的安装与权限说明完成驱动配置，并确认 `HP_LaserJet_1020` 队列能够正常打印普通 PDF 后，再使用本程序。

## 使用方法

1. 选择中文或 English。
2. 选择装订方向。
3. 点击“选择 PDF”。选中文件后不会自动打印。
4. 选择“全部页”或“指定页码”。指定范围时可以填写起始页和结束页；留空分别表示第一页或最后一页。
5. 点击“开始打印”。也可以点击“运行内置方向测试”；该按钮会立即打印两张内置测试页，不受页码范围设置影响。
6. 等待第一面完全打印结束。
7. 整叠取出打印纸，不要改变页序。
8. 已打印面朝下，并让纸张底边先进入进纸盒。
9. 勾选重新放纸确认框，再点击“打印第二面”。

装订方向的判断方法：

- **长边装订：** 像书一样左右翻页，两面文字都应正立。
- **短边装订：** 像台历一样上下翻页，两面文字都应正立；如果不按装订边翻页而直接比较纸张两面，内容相差 180° 是正常现象。

## 构建

在终端中进入项目目录并运行：

```sh
./Scripts/build.sh
```

程序会生成在 `build/HP1020 Manual Duplex.app`。构建脚本会生成 Apple 芯片和 Intel 通用程序，并使用临时签名。

仓库已经包含生成好的 `Resources/AppIcon.icns`，正常构建不需要 ImageMagick。如需从可编辑的 SVG 源文件重新生成图标，请安装 ImageMagick 后运行：

```sh
brew install imagemagick
./Scripts/make_app_icon.sh
```

如需重新生成内置双语测试 PDF，请安装 ReportLab 后运行：

```sh
python3 -m pip install reportlab
python3 Scripts/make_test_pdf.py Resources/two-page-test.pdf
```
